# Working Copy Operations

AnkhSVN exposes common Subversion working-copy operations directly in Visual Studio.

## Common commands

- **Update** brings the working copy to the selected repository revision.
- **Switch** changes a working-copy path to a different repository URL in the same repository.
- **Revert** discards selected local changes.
- **Lock / Unlock** manages Subversion locks for repositories that use locking.
- **Cleanup** repairs interrupted working-copy administrative state.
- **Resolve** records the chosen resolution after a conflict has been handled.

Before switching or performing large updates, commit or safely preserve local work.
