# Subversion Properties

Subversion properties store versioned metadata on files and directories.

Common properties include:

- `svn:ignore` for unversioned items that should normally be ignored.
- `svn:externals` for external working-copy definitions.
- `svn:mime-type` for content type.
- `svn:eol-style` for line-ending handling.
- `svn:keywords` for keyword expansion.
- `svn:mergeinfo` for merge tracking.

Property edits are local working-copy changes until they are committed.
