# Issue Tracking Integration

AnkhSVN can associate commit work with issue-tracking information when the project is configured for it.

Use the issue selector or Pending Changes issue page to review available issue references and include the appropriate issue information with the commit.

Issue-tracker behavior depends on the project and repository configuration; AnkhSVN does not replace the external issue tracker itself.
