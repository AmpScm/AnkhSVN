# Repository Explorer and Checkout

Use **Repository Explorer** to browse repository URLs, inspect remote files and folders, and start repository-based operations.

## Checkout

1. Choose the repository URL.
2. Select the repository folder or project to check out.
3. Choose an empty or appropriate local destination.
4. Select the desired revision when you do not want HEAD.
5. Complete the checkout and open the solution or project in Visual Studio.

Repository URLs must identify a valid Subversion repository location that the configured credentials can access.
