# Source Control Setup

Use AnkhSVN's source-control commands to connect Visual Studio solutions and projects to Subversion working copies.

## Adding a solution

1. Make sure the solution is stored below the intended working-copy root.
2. Use **Add Solution to Subversion** or the appropriate source-control command.
3. Review the proposed repository location.
4. Add the files, then commit them to create repository history.

**Change Source Control** can repair or change Visual Studio bindings when a solution has moved or the detected working-copy root is no longer correct.
