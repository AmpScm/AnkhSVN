# Troubleshooting AnkhSVN

When an AnkhSVN command does not behave as expected:

1. Confirm the working copy is healthy with a current Subversion client.
2. Verify the repository URL and credentials.
3. Update to the latest available AnkhSVN build for your supported Visual Studio version.
4. Reproduce the issue with the smallest practical solution or working copy.
5. Check the [AnkhSVN GitHub issues](https://github.com/AmpScm/AnkhSVN/issues) for known problems.

When opening a new issue, include the AnkhSVN version, Visual Studio version, the operation being performed, and the exact error text or screenshot.
