# Commit and Pending Changes

The **Pending Changes** window is the main place to review local modifications before committing.

## Commit workflow

1. Review modified, added, deleted, and conflicted items.
2. Select the files that belong in the commit.
3. Enter a meaningful log message.
4. Review related issues or changelists when your project uses them.
5. Commit and verify that the working copy returns to the expected state.

Use changelists to group related working-copy changes without changing repository history. Resolve conflicts before committing unless you intentionally need additional local work.
