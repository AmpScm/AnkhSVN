# AnkhSVN Settings

AnkhSVN settings control Subversion behavior and integration with Visual Studio.

## Common settings areas

- Authentication cache and saved Subversion credentials.
- HTTP/HTTPS proxy configuration.
- Diff and merge tool selection.
- Advanced external-tool command-line arguments.
- Solution-specific source-control behavior.

When troubleshooting authentication or connectivity, verify the repository URL, proxy settings, cached credentials, and whether the same repository is reachable with another Subversion client.
